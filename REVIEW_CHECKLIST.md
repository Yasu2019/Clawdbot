# Review Checklist

- [ ] Backup created before large change
- [ ] GitHub push completed, or local backup branch created
- [ ] Only requested files changed
- [ ] No protected Rails layout changed
- [ ] No CSS/Tailwind changed unintentionally
- [ ] No routes changed unintentionally
- [ ] No Docker/OpenClaw service changed unintentionally
- [ ] Diff is minimal
- [ ] Tests/checks run
- [ ] Changed files reported
