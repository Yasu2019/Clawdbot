# 品質保証ユースケース

## 1. IATF 16949 監査準備

入力:
- プロセスマップ
- 内部監査指摘
- 是正処置報告書

出力:
- 審査員想定質問
- プロセスオーナー別準備事項
- 不適合リスク一覧

## 2. 顧客回答メール作成

入力:
- 不具合内容
- 工程情報
- 使用液体、処理条件、検査結果

出力:
- 丁寧な返信メール案
- 事実と推測の分離
- 追加確認事項
