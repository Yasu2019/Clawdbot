# 自己改善フロー（擬似RL）

## これは何か

本格的な重み更新型RLではなく、
**推論時に行動を改善する RL 風ループ**です。

---

## ループ

1. 回答する
2. レビューする
3. 低スコアなら改善する
4. 結果を記憶する
5. 次回の回答前に類似成功例/失敗例を参照する

---

## 擬似コード

```python
answer = agent.solve(task)
review = reviewer.score(task, answer)

if review.total_score < THRESHOLD:
    improved = improver.rewrite(task, answer, review)
    final_answer = improved
else:
    final_answer = answer

memory.store(task, answer, review, final_answer)
future_context = memory.retrieve(similar_task)
```

---

## なぜ効くか

- 同じ失敗の再発率が下がる
- 良い説明の型が蓄積される
- タスク別の得意モデルが見えてくる

---

## 限界

- モデル自体の重みは変わらない
- 評価器が弱いと逆学習が起きる
- 記憶がノイジーだと悪化する
