# Twinmotion Import Handoff

Use this folder for the first Twinmotion PLATEAU LookDev import.

## Import target

`Hon_Atsugi_Station_Plateau_CityOnly_UE5_CmScale.fbx`

## Goal

First make the city alone read as a plausible street/city scene. Do not add RickDias yet.

## First Twinmotion operations

1. Open Twinmotion.
2. Import `Hon_Atsugi_Station_Plateau_CityOnly_UE5_CmScale.fbx`.
3. Check scale and orientation.
4. Add or tune:
   - sky / sun / exposure
   - asphalt / sidewalk / building material
   - trees
   - people
   - vehicles
   - street lights / traffic lights
5. Create 3 city-only camera screenshots.

## Pass condition

The image must look like a city even without RickDias.

## No-go

Do not use v6-style primitive blockout as a final city look.
