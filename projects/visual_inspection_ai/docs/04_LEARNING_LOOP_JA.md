# 安全な自律学習ループ

## 学習トリガー

- 確定済み良品が所定数増えた。
- REVIEW確定総数が所定数増えた。
- 新製品・新不良モードが登録された。
- 誤検出または見逃しがしきい値を超えた。
- ユーザーが手動実行した。

## 手順

1. 確定済みデータだけを抽出。
2. 重複・破損・ラベル矛盾を検査。
3. ロット単位でtrain/validation/testを分離。
4. GPU空き時間にChallengerを学習。
5. 固定テストセットで評価。
6. Championと比較。
7. シャドー運用で差分を蓄積。
8. 人が昇格承認。
9. 旧モデルをArchiveへ退避。
10. 問題時は即時ロールバック。

## 絶対条件

- `auto_promote: false`
- テスト画像を学習へ入れない。
- 1件のユーザー判定だけで再学習しない。
- 評価指標だけでなく不良モード別・重大度別に確認する。
