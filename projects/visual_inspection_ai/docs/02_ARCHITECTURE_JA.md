# アーキテクチャ

```text
カメラ/画像
   ↓
画像品質検査 ──異常──→ REVIEW
   ↓
位置合わせ・ROI
   ↓
┌─────────────────────┐
│ ルール画像処理       │ 外形・穴・色・幾何
│ 既知不良モデル       │ 分類/検出/セグメンテーション
│ 異常検出モデル       │ 未知パターン
└─────────────────────┘
   ↓
判定統合
   ├─ OK
   ├─ NG → 不良マーキング・集計
   └─ REVIEW → ユーザー確定
                    ↓
             学習候補データ
                    ↓
             Challenger学習
                    ↓
       固定評価・シャドー運用
                    ↓
              人による昇格
```

## モジュール境界

- `capture`: カメラ・ファイル入力
- `preprocessing`: 品質・ROI・位置合わせ
- `detection`: 差分、Anomalib、ONNX、GPUモデル
- `measurement`: 校正・外形・穴径
- `decision`: 複数結果の統合
- `review`: 保留・人判定
- `learning`: データセット作成・候補学習・評価・昇格
- `reporting`: CSV・監査証跡
- `api`: UI/API

## 本番と学習の分離

本番推論は短時間・決定論・ロールバック可能性を優先します。学習は別ジョブとし、本番検査のGPU使用を妨げる場合は一時停止します。
