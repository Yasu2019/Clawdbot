# 世界中の不良データを安全に利用する方針

## 原則

世界中のデータを無差別に収集しません。AIは候補情報を整理できますが、学習利用は出典・ライセンス・商用利用可否・品質・ハッシュが確認されたデータに限定します。

## 状態

- `APPROVED`: 公式配布、条件確認、ユーザー承認、ハッシュ確認済み
- `RESEARCH_ONLY`: 非商用・研究評価限定。本番モデルに使用禁止
- `PENDING`: 確認中。隔離領域のみ
- `REJECTED`: 出典不明、条件不適合、品質不良、危険ファイル

## 学習優先順位

1. 実設備・実製品のユーザー確定画像
2. 同条件で撮影した限度見本
3. 同材質・同表面の社内データ
4. 商用利用可能な公開データ
5. 承認済み合成データ
6. 研究限定データ（本番禁止）

## ダウンローダー

`scripts/safe_dataset_downloader.py` は、APPROVED、user_approved、SHA-256、公式URLの全条件が満たされない限り取得しません。
