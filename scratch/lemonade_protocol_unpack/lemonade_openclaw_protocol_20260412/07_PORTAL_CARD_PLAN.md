# Portal Card Plan

## Suggested card name
Lemonade Hub

## Card purpose
A lightweight operational console for:
- service health
- endpoint status
- quick test buttons
- routing summary
- recommended use cases

## Suggested UI blocks
1. service status
2. available endpoint list
3. sample request buttons
4. current routing policy summary
5. warning area for overlap with Ollama features

## Do not do initially
- do not build a giant new dashboard first
- do not duplicate existing Open WebUI or other model UI unnecessarily
- do not create overlapping cards unless a gap is real

## First milestone
A minimal card that shows:
- Lemonade online / offline
- health URL result
- last test timestamp
- guidance: when to use Lemonade vs Ollama
