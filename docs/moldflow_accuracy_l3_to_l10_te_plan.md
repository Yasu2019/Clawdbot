## 実行順序と依存関係

```
[今] L3 → L4: 引継ぎ書§0-1,2の発効待ち(人間2作業) → 自動
L4 → L5: 質量収支KPI実装(1セッション・Codex) + ゴールデン3回連続PASS
L5 → L6: ユーザー実測データ提供(ボトルネック・並行準備可) ← 最重要のお願い
L5 → L7: スパイラルフロー金型ゴールデン追加(1セッション) — L6と並行可
L6+L7 → L8: 実案件適用(ユーザー運用)
L8 → L9: 自動校正実装(1-2セッション)
L9 → L10: 外部基準相関(Moldflow試用版/文献/実測)
```

## AI使用の振り分け (growth_loop_quality_protocol §4準拠)

- 昇格判定・KPI計算・校正ループ: **AI禁止**(決定論)
- 各レベルの実装: Codex/ローカルLLM(定型) + 設計レビューのみ上位モデル
- 文献値・material card調査: Web調査はAI可(結果は数値として決定論ゲートへ)
