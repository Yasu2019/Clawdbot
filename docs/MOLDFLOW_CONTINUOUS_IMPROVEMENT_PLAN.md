# Moldflow風アプリ 24/365 継続改善計画

## 北極星

商用Moldflowを置換したと宣言することではなく、固定した商用参照ケースに
対して、物理的に妥当で再現可能な機能を一つずつ増やす。

## 1サイクル

1. 商用参照値と直近Proxy結果を読み込む。
2. 物理境界、完走、再現性、KPI誤差の順に判定する。
3. 最大の不確かさを減らす最小実験を1件だけ選ぶ。
4. クールダウンと日次上限を通過した場合だけ試験する。
5. 改善候補は固定Golden Caseを3回連続合格するまで採用しない。
6. 悪化・発散・比較不能なら却下し、既知良好版へ戻す。
7. 事実、判断規則、手順、失敗特徴、次実験を記録する。

## 機能ロードマップ

| 優先 | 機能 | 合格条件 |
|---|---|---|
| P0 | VOF充填安定性 | `0 <= alpha <= 1.05`、質量誤差<=2% |
| P1 | 完全充填 | 充填率>=99%、Short Shotなし |
| P2 | 充填時間 | 商用0.9–0.98秒に対する宣言許容差内 |
| P3 | 射出圧力 | 商用10.8794 MPaとの誤差を測定可能 |
| P4 | Cross-WLF材料 | 温度・せん断・圧力依存、材料出典あり |
| P5 | 温度・せん断KPI | 同一定義・単位で比較可能 |
| P6 | 保圧・重量・収縮 | 9.0911 g参照と比較可能 |
| P7 | ウェルド・エアトラップ | 位置と重大度を参照結果と比較 |
| P8 | 冷却・反り | メッシュ独立性と再現性を確認 |
| P9 | ゲート探索/DOE | exact座標、禁止領域、複数ゲート対応 |

## 安全境界

- 監督ループは既定で観測・計画のみ。コードを自動上書きしない。
- 実験は6時間以上の間隔、最大4回/日。
- 本番昇格は自動化しない。3回連続合格と回帰試験を要求する。
- 商用ソフトの秘密情報、認証情報、独自バイナリは収集しない。
- ライセンスと利用規約に従い、公開資料とユーザー所有データだけを使う。
- K10を連続LLM推論で占有せず、失敗した同一条件を無限再試行しない。

## 運転

- 監督のみ: `python scripts/moldflow_continuous_improvement_supervisor.py`
- 1試験を許可: `python scripts/moldflow_continuous_improvement_supervisor.py --execute-trial`
- 監督タスク登録: `powershell -File scripts/install_moldflow_continuous_improvement_task.ps1`
- 試験付き登録は明示指定: `-ExecuteTrial`
