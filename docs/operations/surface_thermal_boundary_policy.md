# 3Dモデル共通の両面熱境界ポリシー

新しい3Dモデルでは、内面と外面を同じ熱境界として扱わない。メッシュまたは面グループに、外面、内面、底面・金型接触面、開口・ベント、孔・コア面を登録する。

各領域は `surface_region_id`、`h_surface_W_m2K`、面温度、法線を持つ。仮想計算では領域別係数を明示し、実測計算では金型温度、接触熱伝達、空気側熱伝達、コア条件へ置き換える。

契約ファイル: `config/surface_thermal_boundary_contract.json`

受入条件: 内外面が分離され、すべての面グループに有限な熱境界値があり、結果マニフェストへ記録されていること。
