# 引張試験の応力換算を原本で検証する

INC-P1R58F-MR536-SECTION-20261118-01、2026年11月21日更新。

複数の試験片群で公称応力の比が公称板厚の比に近く、弾性域の勾配にも群間差があった。過去記録は、応力の計算に異なる断面積を使ったと断定していた。原本と加工版を再取得して全試験データを照合したところ、両者は一致した。記録されていたのは応力とひずみの値で、元荷重、試験片の実測断面積、セルの換算式は確認できなかった。

原因の判定を訂正した。強度データの整合性に疑義がある。断面積の取り違えは有力仮説で、供給元での計算過程は未確定。疑義のある群を材料則の変更に使うことは保留する。

| 工程管理 | 更新した内容 |
|---|---|
| FMEA | 疑義のある曲線を採用すると荷重・破断の予測が変わる。データの観測、推定原因、確認済み原因を別欄で保持する。評点は未設定。 |
| FTA | 群間差は観測済み。断面積、試験条件、試験片と生産材の対応は未解決の枝として残す。 |
| QC工程表 | 受領原本のハッシュ、荷重・寸法列、単位、数式・外部参照を確認し、変換前後の元シートを照合してから採用審査に進む。 |
| コントロールプラン | 材料表の版ごとに実施。元荷重・断面の裏付けがなければ、推定補正値を正式入力にしない。原本取得と原因確定を別々に記録する。 |

再確認により、過去の原因断定を訂正し、未確認の補正値の採用を回避した。物理的原因の確認と量産工程の妥当性評価は継続事項。
