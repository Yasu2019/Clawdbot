# OpenFOAM pressure-density mass closure — sanitized knowledge card

In compressible VOF molding solvers, phase density is evaluated from absolute EOS pressure `p`; its `psi` is `d(rho)/d(p)`. A reduced-pressure increment `delta(p_rgh)` may also contain a hydrostatic `-gh*delta(rho)` coordinate shift after thermal/crystallinity density changes. Applying that shift again through `psi` can create a spurious phase-density increment. Keep the absolute-pressure and reduced-pressure predictions as separate diagnostics. A source-level correction to use the absolute EOS pressure increment passed seven standalone C++98 kernel builds/tests and 35 Python source/parser contracts, but it is not yet rebuilt or validated in OpenFOAM Foundation 3.0.0. Preserve Foundation 3.0.0 upstream snapshots as references, and require static/dynamic rebuild plus nonzero-gravity thermal runtime evidence before claiming closure. Root cause remains UNKNOWN pending that runtime test. Evidence note: `docs/knowledge/INC-OPENFOAM-ABSOLUTE-PRESSURE-DENSITY-UPDATE-20261028-01.md`.
