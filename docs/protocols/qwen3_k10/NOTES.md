# 補足メモ

1. 「35Bだから必ず重い」のではなく、MoEによりアクティブ計算量は軽くなる。
   ただし、モデル全体が小さくなるわけではないため、RAM/VRAM負荷は依然大きい。

2. CPU-onlyでも動作可能性はあるが、快適さは用途依存。
   日常主力にするより、重量級スポット起用が現実的。

3. 長いコンテキストは便利だが、速度と安定性のコストが増える。
   実務ではRAG併用のほうが賢い。

4. 安全性上、ローカルAIでも自動ファイル変更や自動削除は慎重に扱うこと。

5. vLLMや一部サービング構成では reasoning parser の考慮が必要な場合がある。
