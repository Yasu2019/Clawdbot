# Incident card: false remote identity mismatch from local PowerShell parsing

On 2026-11-01 JST, a compound SSH diagnostic was split by the local PowerShell shell, so local output was mistaken for remote identity. A read-only encoded PowerShell probe and independent Tailscale/SSH host-key checks later confirmed the intended Windows host. No remote task, process, calculation, checkpoint, configuration, or security setting changed. Prevention: encode compound PowerShell commands for SSH and verify the remote machine identity/account and independent host route before any state-changing operation. Preserve separate active work; do not dispatch FEM until existing RAM and production gates are resolved. A separate intermittent peer was not reachable over Tailscale at the observation time; its cause remains unknown.
