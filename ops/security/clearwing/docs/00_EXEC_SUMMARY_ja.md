# 00_EXEC_SUMMARY_ja

## 何をするパックか
このパックは、Clearwing を軸にした **ローカル完結型の脆弱性診断環境** を立ち上げるためのたたき台です。
主眼は「強いモデル」ではなく、次のワークフローを再現することです。

1. 対象コード／対象サービスの優先度付け
2. AI による仮説出し
3. 静的解析ツールによる裏取り
4. 安全なテスト環境での再現確認
5. 報告書生成
6. 人間承認のもとで修正反映

## 鈴木様向けの実務メリット
- ソースコードを外部へ出さずに点検しやすい
- QA の「仮説→再現→是正→証跡」の考え方と相性が良い
- 将来的に OpenClaw / n8n / Paperless / Qdrant 側へつなぎやすい
- 品質保証部門の内部利用なら、セキュリティ点検の型を標準化しやすい

## 実装方針
- まずは**安全優先の最小構成**
- 攻撃的・破壊的アクションはすべて HITL
- ネットワーク診断は**自社許可済みの検証環境だけ**
- 本番環境直撃は禁止
