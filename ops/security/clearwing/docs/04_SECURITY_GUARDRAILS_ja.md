# 04_SECURITY_GUARDRAILS_ja

## 絶対条件
- 診断対象は許可済み資産のみ
- 本番環境へ直接の能動試験は禁止
- 危険操作は人間承認必須
- 外部サービスへのコード送信禁止

## 禁止例
- `rm -rf`
- DB削除・更新
- 本番再起動
- 未許可ホストへのポートスキャン
- 認証回避の試行
- 第三者システムへのテスト

## 推奨ガード
1. Docker network を分離
2. 対象ホストは allowlist 管理
3. 監査ログを保存
4. APIキーは `.env` のみ
5. 生成AIには secrets を直接貼らない
6. 結果は必ず人がレビュー

## 人間承認が必要な場面
- 書き込みを伴う修正
- 疑似攻撃の実行
- コンテナ再起動
- 依存更新
- CI への組込み
