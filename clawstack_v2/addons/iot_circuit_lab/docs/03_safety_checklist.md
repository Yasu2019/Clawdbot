# 03. 電気的安全チェックリスト

## ESP32 ADC入力

- [ ] ADC入力電圧が0〜3.3Vを超えない
- [ ] センサー最大出力時もADC保護範囲内
- [ ] マイナス電圧が入らない
- [ ] 入力保護抵抗を検討した
- [ ] 必要に応じてクランプダイオードを検討した
- [ ] RCフィルタの時定数が応答要求に合っている
- [ ] GND共通化のリスクを確認した
- [ ] ノイズで閾値を跨がないようヒステリシスを入れた

## 0-10V信号を読む場合

- [ ] 0-10Vを直接ESP32に入れていない
- [ ] 分圧後の最大電圧が3.3V以下
- [ ] 分圧抵抗値が大きすぎてノイズに弱くなっていない
- [ ] 小さすぎて信号源に負荷をかけていない
- [ ] PLC/設備側との絶縁要否を確認した

## 4-20mA信号を読む場合

- [ ] シャント抵抗で電圧変換した
- [ ] 最大20mA時の電圧がADC範囲内
- [ ] 断線時・過電流時の挙動を想定した
- [ ] 絶縁入力の必要性を確認した

## リレー/ソレノイド/モータ周辺

- [ ] フライバックダイオードまたはスナバを入れた
- [ ] ESP32ピンで直接コイルを駆動していない
- [ ] トランジスタ/MOSFETの定格を確認した
- [ ] 電源ラインのノイズ対策を確認した
- [ ] 実機接続前に別電源・ダミー負荷で確認した

## 運用

- [ ] Wokwiでファーム動作確認済み
- [ ] Node-REDで異常判定確認済み
- [ ] 実機接続前にテスターで電圧確認済み
- [ ] 設備の安全回路には介入しない
- [ ] 品質記録用途の場合は時刻同期を確認した
