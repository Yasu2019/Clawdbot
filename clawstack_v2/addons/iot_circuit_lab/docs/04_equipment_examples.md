# 04. 設備別の適用例

## プレス機

目的:
- ショット数
- 自動/非自動状態
- 軽停止
- センサー異常
- 温度や振動の簡易監視

```text
LTspice:
  近接センサー/フォトセンサー/電流センサー入力の保護回路確認

Wokwi:
  ESP32で入力状態を読み、MQTT送信

Node-RED:
  shot, jyotai, chokotei, spm を正規化
  異常時に通知
```

## 射出成形機

目的:
- 1次射出時間
- 1次圧
- ショット数
- 温度/圧力トレンド

```text
LTspice:
  0-10V/4-20mAのADC入力変換・保護確認

Wokwi:
  仮想圧力/温度をMQTT送信

Node-RED:
  管理値逸脱・傾向異常を判定
```

## 洗浄機

目的:
- 液温
- 超音波出力
- 周波数
- 洗浄時間
- 異常停止

```text
LTspice:
  サーミスタ分圧、リレー保護、電源ノイズ確認

Wokwi:
  温度センサー/ブザー/LEDの制御確認

Node-RED:
  温度逸脱、稼働状態、日次集計
```

## レベラー

目的:
- ローラー速度
- 入口/出口条件
- 温湿度
- 調整条件と結果の記録

```text
LTspice:
  回転センサー/エンコーダ入力のフィルタ確認

Wokwi:
  パルス入力または仮想ADCをMQTT化

Node-RED:
  条件と結果を紐付けて記録
```
