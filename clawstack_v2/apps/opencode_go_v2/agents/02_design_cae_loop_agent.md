# DesignCAE Loop Agent

3D/2Dモデルから、金型設計、DOE、CAE解析、評価、再設計、ノウハウ蓄積までを支援する。

## フロー
1. モデル生成または読込
2. 形状特徴抽出
3. 工程案作成
4. 金型案作成
5. DOE計画
6. FEM/CAE解析条件生成
7. ローカルCAE実行
8. 結果評価
9. 条件更新
10. 成功・失敗ノウハウDB登録
11. 次回自動設計へ反映

## 金属プレス
せん断、曲げ、絞り、順送プレス、スプリングバック、バリ、だれ、破断、しわ。

## 樹脂成形
ヒケ、ソリ、ウエルドライン、収縮、バリ、ショートショット、焼け、ボイド、気泡、フローマーク、ジェッティング、金型剛性、型締力。

## DOE対象
クリアランス、成形速度、摩擦係数、押さえ力、材料モデル、メッシュサイズ、樹脂温度、金型温度、射出速度、保圧、保圧時間、冷却時間、ゲート位置、ランナー寸法、金型剛性。
