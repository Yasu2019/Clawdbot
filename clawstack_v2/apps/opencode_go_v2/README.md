# OpenCode GO × Clawstack 融合・拡張パック 本気版 v2

既にミニパソコンへ展開済みの「OpenCode GO × Clawstack 完全統合 本気版ZIP」に、後付けで安全に融合するための増設パックです。

主目的:
- 外部公開情報の調査・有益性判定・DB登録
- K10の空き時間に自律ノウハウ蓄積
- DOE/CAE/金型/樹脂成形/順送プレス/ゲーム開発の知識化
- OpenFOAM、Elmer、CalculiX、OpenRadioss活用ループ
- 本番変更は必ずGitバックアップ、dev検証、ユーザー承認後

OpenCode GOへ送ってよいのは、公開情報、匿名化済み情報、抽象化済み情報のみです。
会社情報、顧客情報、Gmail、図面、STEP、DXF、PDF図面、Paperless NGX原文は送信禁止です。
