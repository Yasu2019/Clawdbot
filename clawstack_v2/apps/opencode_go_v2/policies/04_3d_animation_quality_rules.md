# 3Dキャラクター動画生成 絶対ルール

## 【最重要】静止画・イラスト禁止

**静止画・イラスト・スライドによる動画生成は絶対に禁止。**
すべてのキャラクターは3Dモデルを使用し、以下を必ず実装すること。

---

## 必須アニメーション要件

### 1. リップシンク（Lip Sync）
- キャラクターのセリフに完全に同期した口の動き
- フォネーム（音素）ベースの口形アニメーション必須
- 無音区間では口を閉じること
- 実装方法（優先順）:
  1. **Blender + Rhubarb Lip Sync** → 顎ボーン・モーフターゲット駆動
  2. **Wav2Lip後処理** → 3Dレンダリング後にフェイス合成（フォールバック）

### 2. 瞬き（Blink）
- 自然な間隔（3〜6秒ごと）でランダム瞬き必須
- 瞬きの所要時間: 0.1〜0.15秒（約3〜4フレーム at 30fps）
- 実装方法:
  1. **瞼モーフターゲット**（blend shape "blink"/"eye_close"）
  2. **瞼ボーン**（eyelid bone）アニメーション
  3. **テクスチャスワップ**（目閉じテクスチャへの切替）

### 3. ボディモーション（Body Motion）
- セリフの音量・強調に同調した自然な身体動作
- 必須モーション:
  - **呼吸** (Spine/Spine1ボーン: Y軸±0.003, 周期3〜4秒)
  - **頷き** (Neckボーン: X軸 発話区切りで0.05〜0.1rad揺れ)
  - **重心移動** (Hipsボーン: 会話中に微細な左右揺れ)
  - **発話強調** (Spine2ボーン: 重要発言時に前傾+0.05rad)
  - **手振り** (ArmボーンGroupL/R: 説明時に自然なジェスチャー)

### 4. 目線（Eye Gaze）
- カメラ方向を基本とし、会話相手キャラクター方向への自然な視線移動
- 瞬き直前の目線そらし（自然な視線回避）

## 技術スタック（確定）

### 現在のGLBモデルの制約（重要）
- **Mixamorigリグ**: 体幹・四肢ボーン41本 ✅
- **顎ボーン(jaw)**: なし ❌ → Blenderで追加必要
- **瞼ボーン(eyelid)**: なし ❌ → Blenderで追加必要
- **モーフターゲット**: なし ❌ → Blenderで追加必要

### 推奨パイプライン（Phase 1）

```
VoiceVox TTS (WAV生成)
    ↓
Rhubarb Lip Sync (WAV → フォネームJSON)
    ↓
Blender Python headless
  ├─ GLBインポート
  ├─ 顎ボーン追加 + フォネーム → 顎回転アニメーション
  ├─ 瞼ボーン追加 + 瞬きアニメーション
  ├─ 呼吸・頷き・重心移動の手続き的アニメーション
  └─ EEVEE レンダリング → PNG連番
    ↓
FFmpeg → MP4合成
```

### 推奨パイプライン（Phase 2: 品質向上）
- Mixamo Full Rig（顎・瞼ボーン含む）へのリリギング
- またはVRM形式への変換（52ブレンドシェイプ完備）

## 動画構成ルール（IATF内部監査教材）

**PDFの内容を省略せず全て盛り込むこと。**

1. **オープニング**（ブルマMC）: 箇条・テーマ紹介、要求事項全体概要
2. **現場監査シーン**（悟空×御飯/トランクス）: PDF記載の全チェックポイントを対話形式で
3. **問題点提示**（17号・18号）: 不適合事例・指摘事項を漏れなく
4. **クローズミーティング**（亀仙人）: 監査証跡・記録要件まとめ
5. **改善対策**（御飯/トランクス）: 是正処置・予防処置・期限

---

## 禁止事項

- ❌ 静止画・イラスト・スライドによる動画
- ❌ キャラクターが棒立ちのまま音声だけ流す動画
- ❌ PDFの内容を省略・要約した動画
- ❌ リップシンクなしの口を動かさないキャラクター
- ❌ 瞬きなしのキャラクター
- ❌ Wav2Lip単独使用（3Dボディアニメなしの顔だけ合成）
