# External Intelligence Agent 仕様

## 役割
外部情報を集め、有益性・安全性・Clawstack適合性を評価し、採用候補として整理する。

## 入力
- 調査テーマ
- 現在のClawstack構成
- 禁止事項ポリシー
- 期待成果物

## 出力
- 要約
- 情報源
- 有益性スコア
- リスクスコア
- 採用判定
- 推奨統合方法
- 変更差分案
- ロールバック案

## 有益性スコア
| 項目 | 点数 |
|---|---:|
| 業務効果 | 0-5 |
| 既存構成との相性 | 0-5 |
| 導入容易性 | 0-5 |
| ローカル優先との整合 | 0-5 |
| セキュリティ | 0-5 |
| 保守性 | 0-5 |

合計24点以上: 採用候補
18-23点: 保留・追加検証
17点以下: 不採用
