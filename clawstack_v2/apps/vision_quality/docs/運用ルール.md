# 運用ルール

## 基本原則

AI判定は最終判定ではありません。AIは候補提示、根拠整理、見落とし防止に使います。

## NG候補が出た場合

1. 検査員が画像を確認
2. 限度見本と比較
3. 必要なら現物確認
4. 最終判定を登録
5. AI判定が誤りなら「誤判定」として保存

## 禁止事項

- AI判定だけで出荷停止を決める
- AI判定だけで顧客へ報告する
- 図面や顧客要求をAIに自由解釈させる
- 単位や公差をAI推定に任せる

## 推奨

- Lot、設備、ショット、SPM、チョコ停止との相関を見る
- 同一Lot内の良品/不良を比較する
- 再発防止書にAI根拠をそのまま転記せず、人間が確認する
