# 導入手順

## 1. 配置

```bash
mkdir -p /opt/clawstack/modules
unzip openclaw_vision_quality_inspection_full.zip -d /opt/clawstack/modules/vision_quality
cd /opt/clawstack/modules/vision_quality
cp .env.example .env
```

## 2. 起動

```bash
docker compose -f docker-compose.vision.yml up -d --build
```

## 3. 動作確認

```bash
curl http://localhost:18795/health
```

## 4. Portal登録

`portal/cards/vision_quality_card.json` の内容を既存Portalのカード一覧へ追加します。

## 5. Node-RED連携

`nodered/flow_vision_quality_template.json` をNode-REDへインポートします。

## 6. 実運用前の設定

- 撮影条件を固定
- 照明条件を固定
- 良品/不良画像を収集
- 限度見本とリンク
- 検査員レビュー画面を追加
- 判定ログの保管期間を決める
