# 04. インシデント対応手順

## 対象
- APIキー流出疑い
- 顧客図面・IATF文書の誤送信疑い
- AIエージェントの異常操作
- npm/pip導入後の不審挙動

## 初動
1. ネットワーク切断または対象コンテナ停止。
2. `docker compose ps` と `docker logs --tail` を保存。
3. `scripts/audit/collect_evidence.sh` を実行。
4. 関係するAPIキーを無効化・再発行。
5. 影響範囲を記録。

## 報告項目
- 発見日時
- 影響対象
- 流出可能性のある情報
- 実施した封じ込め
- 是正処置
- 再発防止策
