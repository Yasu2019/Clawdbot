# ユーザーマニュアル 日本語版

## 代表的な使い方

### RCフィルタ確認

1. Portalで `RC low-pass` を読み込む
2. RとCを変更
3. シミュレーション実行
4. `vmax_out` や `vfinal` を確認
5. 実機測定の候補値を決める

### センサー入力フィルタ確認

1. `sensor_input_filter` を読み込む
2. 入力電圧、Rfilter、Cfilterを変更
3. 応答遅れと平滑化を確認
4. PLC/ADC側の入力仕様と比較

### 分圧回路の許容差確認

1. `divider_tolerance` をベースにする
2. Rtop/RbotをPythonまたはOpenClawから変更
3. worst caseの出力電圧を確認

## レポートに書くべき項目

- 回路目的
- ネットリスト
- 部品値
- 使用モデル
- 解析種別 `.op` / `.tran` / `.ac`
- 結果
- 実測で確認すべき点
- モデル限界

## 製造業QAでの用途例

- 治具入力信号のチャタリング対策
- フォトセンサー/近接センサー出力の遅延確認
- プレス機・成形機の信号取り込みフィルタ確認
- 電源投入時の遅延や突入の概算
- 測定器入力保護の一次検討
