# Qwen / Gemma / ローカルLLM引継ぎメモ

## 目的

ローカルLLMに、回路シミュレーションの使い方を安定して理解させるためのRAG投入用ドキュメントです。

## 基本方針

- LTspiceはWindows GUIで回路作成・波形確認
- ngspiceはDocker内で自動解析
- OpenClawからはFastAPI `/simulate` を呼ぶ
- 回路ネットリスト、ログ、測定値を必ず保存

## ローカルLLMに守らせるルール

1. 回路シミュレーション結果を実測値として扱わない。
2. モデル条件、部品値、温度、許容差を必ず明記する。
3. 不明な素子モデルは勝手に断定しない。
4. 顧客提出資料では、出典と検証者を残す。
5. 電源・安全回路では、シミュレーションのみで安全判断しない。
6. 既存Clawstackを大規模に書き換えない。

## よく使う解析テーマ

- RCフィルタの時定数
- センサー入力の平滑化
- 分圧回路の許容差影響
- 電源投入時の突入・遅延
- 保護抵抗・クランプ回路の概算
- プレス機・成形機信号のチャタリング対策

## ツール呼び出し例

```json
{
  "name": "sensor_input_filter_case1",
  "netlist": "* ngspice netlist here"
}
```
