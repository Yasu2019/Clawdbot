# Acceptance Checklist

## Memory quality
- [ ] lessons are concrete
- [ ] lessons cite real evidence
- [ ] lessons distinguish fact from inference
- [ ] duplicate noise is controlled

## Operational behavior
- [ ] system does not inject stale lessons blindly
- [ ] low-confidence lessons are gated
- [ ] failures produce useful memory entries
- [ ] successful repeated tasks become compact playbooks

## Safety
- [ ] no automatic risky write action from unreviewed memory
- [ ] human audit trail exists
- [ ] rollback path exists
- [ ] raw traces are preserved separately

## Value
- [ ] repeated troubleshooting gets faster
- [ ] fewer repeated tool mistakes occur
- [ ] token usage remains acceptable
- [ ] human trust improves rather than declines
