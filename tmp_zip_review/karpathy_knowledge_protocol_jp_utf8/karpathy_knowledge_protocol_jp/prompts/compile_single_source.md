# Claude Code Prompt: Compile Single Source

以下の raw 文書を読み、Markdownノートを1つ作成してください。

要件:
1. 日本語で出力
2. 推測と事実を分ける
3. 用語定義を含める
4. 関連ノート候補を最低3件挙げる
5. Open Questions を残す
6. 最後に Sources を列挙する
7. wiki/topic 用に整ったMarkdownで出力する

出力構成:
- Summary
- Key Facts
- Definitions
- Causes / Mechanisms
- Evidence
- Related Notes
- Open Questions
- Next Actions
- Sources
