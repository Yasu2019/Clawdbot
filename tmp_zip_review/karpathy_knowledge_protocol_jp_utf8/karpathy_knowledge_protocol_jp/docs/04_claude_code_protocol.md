# 04 Claude Code Protocol

## 目的
Claude Code に対し、単なる要約ではなく、**知識構造化エージェント**として動いてもらうための運用指針です。

## 基本方針
1. raw を直接読む
2. processed を生成する
3. wiki を更新する
4. 既存ノートと必ず関連付ける
5. 矛盾や不明点を残す

## 実行単位
### 小さい単位
- 1記事
- 1PDF
- 1議事録
- 1テーマ

### 中くらいの単位
- 同一テーマ10資料
- 同一不具合群
- 同一工程群

### 大きい単位
- 1プロジェクト全体
- 1製品群
- 1監査対象範囲

## 禁止寄りの運用
- raw原本を勝手に消す
- 出典なしで断定する
- wikiに未確認事項を事実として書く
- 同名ノートを乱造する

## 推奨ルール
- 1ノート1主題
- 出典を末尾に列挙
- 関連ノートを最低3件張る
- Open Questions を残す
- 次の確認行動まで書く
