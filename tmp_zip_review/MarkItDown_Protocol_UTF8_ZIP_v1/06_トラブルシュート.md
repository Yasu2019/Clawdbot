# トラブルシュート

## 1. 日本語ファイル名で失敗する
- PowerShell / Python のエンコーディングを UTF-8 に揃える
- Windows パス長制限を疑う
- OneDrive 同期中のロックを疑う

## 2. 表が崩れる
- Excel / PDF の元構造依存
- Docling 併用を検討
- 表をそのまま埋め込みすぎず、後段で再整形ルールを持つ

## 3. スキャンPDFで中身が薄い
- OCR を先にかける
- OCR プラグインや別OCR基盤の併用
- 画像説明や VLM を補助利用

## 4. ZIP が多層で失敗する
- 事前に安全展開
- パス traversal 対策
- 一時フォルダ運用
- 展開失敗時の隔離

## 5. Windowsで文字化けする
- UTF-8 with BOM で保存
- `Out-File -Encoding utf8` を使う
- Excel で CSV を開くときはインポートを使う
