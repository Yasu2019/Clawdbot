# 安全導入プロトコル

## Phase 0: 事前バックアップ
1. 既存 Obsidian Vault を丸ごとバックアップ
2. Git 管理していない場合は zip バックアップ作成
3. Vault サイズ、ノート数、主要フォルダを記録

## Phase 1: 隔離検証
1. 新規検証 Vault を作成
   - 例: `obsidian_arscontexta_sandbox`
2. Claude Code から plugin を導入
3. `/arscontexta:setup` を実施
4. small sample のみ投入
   - 会議メモ 5件
   - 技術メモ 5件
   - 動画要約 5件
5. `/ralph` または関連生成コマンドを実行
6. 生成結果を監査

## Phase 2: 機能評価
確認項目:
- 自動リンクは妥当か
- MOC は読めるか
- note schema は過剰でないか
- 過去メモとの接続は有用か
- ノイズノートが大量発生しないか
- 再起動後も安定して使えるか

## Phase 3: 既存運用との比較
比較対象:
- 既存 Obsidian 手動運用
- 既存 RAG 検索
- arscontexta 導入後運用

比較指標:
- 情報再発見時間
- 関連ノート到達率
- 同内容の再説明回数
- AI に渡す文脈量
- 人間が読むときの分かりやすさ

## Phase 4: 限定本番
対象を 1 ドメインに絞る:
- 動画要約系
- 技術検討メモ
- 監査 / 品質知見
- ローカルLLM / エージェント構成ログ
上記のうち 1 つだけ

## Phase 5: 本採用 or 巻き戻し
- 良ければ対象ドメインを追加
- 悪ければ sandbox のまま破棄
