# 03 実装アーキテクチャ

## 推奨レイヤ
### Layer 1: Execution
Codex / Claude / Antigravity / OpenClaw

### Layer 2: Routing
LiteLLM

### Layer 3: Knowledge
Qdrant / Paperless / 文書前処理

### Layer 4: Observability
Langfuse / 実行ログ / 成否ラベル

### Layer 5: Harness
Archon風比較ハーネス
- 同一タスクを複数回実行
- 出力差分を記録
- 安定性スコア算出

### Layer 6: Learning
Hermes風改善候補生成
- 成功 / 失敗タスクから候補抽出
- スキルとして提案
- 人間レビュー後登録

### Layer 7: Voice
Vox-CP2または既存音声系
- 必要性が固まった時のみ追加

## 重要な制御点
- Skill Registry を分離する
- 自動登録ではなく審査制にする
- すべての改善候補に根拠ログを紐づける
