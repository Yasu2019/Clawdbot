# Kinematics Hub Requirements

Target URL:
http://localhost:8088/apps/kinematics_hub/index.html

## 1. 目的
プレス金型の各ステージで、どのような加工が行われ、製品がどのような形状へ変化していくかを、
ユーザーに視覚的に理解してもらうこと。

## 2. 基本方針
- 厳密な FEM は今回不要
- 視覚的分かりやすさを最優先
- 工程の順番と形状変化が直感的に分かること
- 必要に応じて簡易アニメーションを使うこと

## 3. 表示すべき最低情報
- Stage No.
- Stage name
- Operation type
- 前形状
- 後形状
- 工程説明
- 注意点
- 必要なら工具の簡易表示

## 4. 工程種別例
- ピアス
- 外形抜き
- 曲げ
- フォーミング
- 絞り
- トリム
- パイロット
- キャリア送り
- 切り離し

## 5. UI要件
- ステージ一覧パネル
- ステージ選択
- 前へ / 次へ
- 再生 / 停止
- 表示切替
- 注釈表示
- ハイライト

## 6. 推奨表現
- 加工部の色分け
- 曲げ方向の矢印
- 製品部とスクラップ部の分離表示
- 加工前後の比較
- カメラ位置のプリセット
- ステージごとの短い説明文

## 7. 許容される近似
- 幾何学的変換
- ルールベースのステージ説明
- 単純化した工具表示
- アニメーションによる移動 / 曲げの表現

## 8. 望ましい実装
- ステージ定義を JSON 等の外部データで保持
- UI ロジックとステージデータを分離
- 後から手修正しやすい構造
- 将来、簡易 CAE や FEM 連携へ発展可能な構造
- OpenRadioss / OpenFOAM へ条件を渡しやすい構造

## 9. 完了条件
- ユーザーが、各ステージで何が起きるか説明できる
- 形状変化の流れが理解できる
- 金型設計案のイメージ共有に使える
