# OpenFOAM pressure-unit calibration correction

## Summary

NG: raw OF pressure about 65,240 Pa was recorded as 65.24 MPa. Correct value is
0.06524 MPa. This reversed the rheology calibration direction. MF EOF pressure is
13.784831 MPa; r32 EOF is 0.06517 MPa. Source cases remain intact.

## QC process table

| Control | Gate | Result | Evidence |
|---|---|---|---|
| Raw unit | OF `p` dimensions Pa | pass | `1.05/p` raw maximum 65170 |
| Conversion | Pa / 1e6 | pass | 0.06517 MPa |
| Fill timing | compare separately | close | MF 1.078 s, OF 1.00-1.10 s |
| k proposal | bounded 1e-6..50 | pass | 10.576058 |
| Accuracy claim | PROXY_GAP only | pass | handoff and DB |

## FMEA

| Mode | Effect | Countermeasure |
|---|---|---|
| kPa called MPa | 1000x pressure error | typed converter and test |
| wrong k direction | worse calibration | ratio sign/direction test |
| proposal called validation | false confidence | rerun gate |

## FTA / 5 Why

Bad k <- bad pressure comparison <- unit label error <- divide by 1,000 <- no
raw-unit conversion test and no provenance beside the proxy.

## Fishbone

- Method: manual proxy entry.
- Measurement: Pa/kPa/MPa schema ambiguity.
- Code: no typed converter in the old record path.
- Validation: fill success obscured pressure failure.
- Process: calibration promoted before raw-field audit.

## Countermeasures / forbidden

- Use `pa_to_mpa`; test 65,240 Pa -> 0.06524 MPa.
- Keep fill and pressure gates independent.
- Verify k=10.576058 in an identical single-variable trial.
- Forbidden: `/1000` values labeled MPa.
- Forbidden: changing multiple physics parameters in the pressure trial.
- Forbidden: `MOLDFLOW_EQUIVALENT` before declared comparison gates pass.
