# Moldflow mixed entity ID correction

## Summary

NG: 1,818 node coordinates joined only 30.77% of typical 3,552-row elemental
results and 0% of four 40-row cooling-circuit results. OK target: preserve nodes,
TRI3, and 1DET as separate associations and calculate element centroids. No source
CSV, Study, STL, or OpenFOAM case was changed.

## QC process table

| Control point | Input | Gate | Evidence |
|---|---|---|---|
| Active study | Synergy StudyDoc | exact expected study | macro log `ACTIVE=` |
| UDM entities | SUMR vs parsed | counts equal | `PASS1` / `PASS2` |
| Coordinate units | UDM + COM node | error <=0.001 mm | `UDM_TO_MM_SCALE` |
| Connectivity | TRI3/1DET nodes | missing=0 | `PASS2 missing=0` |
| Output promotion | `.part` | all gates pass | final CSV only after validation |

## FMEA

| Mode | Effect | RPN direction | Countermeasure |
|---|---|---|---|
| element ID labeled NodeID | spatial corruption | high | association-specific entity map |
| circuit ID has no node match | Cool data loss | high | 1DET centroid mapping |
| UDM unit assumption | 1000x scale error | critical | live COM reference comparison |

## FTA / 5 Why

Spatial join NG <- mixed dataset associations <- generic integer array exported as
`NodeID` <- schema omitted entity type <- validation checked values but not join
coverage. Node-only export was valid but insufficient for elemental and circuit data.

## Fishbone

- Method: coordinate step added after result export.
- API: `Get*Data` association varies by dataset.
- Measurement: no full-join KPI.
- Geometry: NODE/TRI3/1DET locations differ.
- Data: generic `NodeID` header hid the distinction.

## Countermeasures and forbidden patterns

- Add `04_export_entity_geometry.vbs`; parse version-native UDM records.
- Require declared counts, connectivity, scale, and atomic-output gates.
- Select geometry by field association before OpenFOAM interpolation.
- Forbidden: joining every result ID to node coordinates.
- Forbidden: assuming UDM coordinates are mm.
- Forbidden: calling a partially joined pack validated or Moldflow-equivalent.
