# Codex / Claude 判断フロー

## 0. 前提
本フローは、OpenClaw環境で3D AIワークフローを導入する前に実施する。

## 1. 競合確認
- 既存コンテナ名重複はないか
- 既存ポート重複はないか
- GPUメモリ消費が既存業務を圧迫しないか
- 既存Portalカードと役割が競合しないか

## 2. 技術妥当性
- ローカルで動くか
- Windows主体の環境で実行しやすいか
- Blender中心の運用に無理なく接続できるか

## 3. 運用妥当性
- 人手を入れるポイントが明確か
- 完全自動でなくても、手戻りが少ないか
- 失敗時の分岐が定義されているか

## 4. 判定
- 採用: すぐ組み込める
- 部分採用: 一部だけ入れる
- 保留: 情報不足 / リスク未解決
- 非採用: コスト / 安定性 / 競合面で不適
