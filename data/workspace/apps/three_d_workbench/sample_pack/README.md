# 3D Workbench Sample Pack

This is a lightweight demo set for the folder-first 3D workflow.

## Suggested usage

1. Copy the manifest paths into the matching `E:\Assets\3D` folders.
2. Put raw files into `Incoming`.
3. Edit in `Working`.
4. Publish reviewable outputs into `ExportReady`.
5. Keep caches separated in `Cache`.

## Notes

- The sample is intentionally small.
- It is designed for Portal navigation and quick manual testing.
- Unreal stays out of the always-on path.
