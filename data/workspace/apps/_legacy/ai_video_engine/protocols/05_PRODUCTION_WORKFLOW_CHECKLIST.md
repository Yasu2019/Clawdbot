# Production Workflow Checklist

## Pre-production
- [ ] Objective is defined in one sentence
- [ ] Target duration is short enough for testing (3-5 sec recommended)
- [ ] JSON created from template
- [ ] Camera / motion / lighting separated
- [ ] Exclusions written explicitly

## Constraint assets
- [ ] Start pose image prepared
- [ ] End pose image prepared
- [ ] Framing consistency checked
- [ ] Character identity references prepared

## Motion reference
- [ ] Human motion recorded
- [ ] Motion clip duration is appropriate
- [ ] Background clutter minimized
- [ ] Motion matches target shot

## Generation
- [ ] Only one shot generated first
- [ ] Generation version logged
- [ ] Output linked to JSON version

## Review
- [ ] Face consistency checked
- [ ] Body realism checked
- [ ] Camera stability checked
- [ ] Physics / cloth / hair checked
- [ ] Artistic intention checked

## Revision
- [ ] Only failing blocks edited
- [ ] Notes recorded
- [ ] New version number assigned
