# VNCCSを品質保証・外観検査AIへ応用する計画

## 狙い
画像生成AIの強みを、単なるイラスト作成ではなく、照明・角度・構図のばらつきを制御した疑似データ生成に使います。

## 対象例
- キズ
- 打痕
- シミムラ
- バリ
- 付着
- 変形
- めくれ

## 推奨アプローチ
### Phase 1：人間用教材
ポーズ・光源の変化が画像に与える影響を理解する教材として使います。

### Phase 2：検査AIの事前学習/データ拡張
実写画像を主、生成画像を補助として使います。

### Phase 3：条件探索
DOEで光源位置・強度・カメラ角度を振り、欠陥が最も見えやすい条件を探索します。

## NG運用
- 生成画像だけで量産判定モデルを作る
- 実写とのドメインギャップを評価しない
- ラベル品質を確認せず一括投入する

## 重要
生成AI画像は「補助データ」です。最終判断は実写データ・現場評価・統計評価と組み合わせてください。
