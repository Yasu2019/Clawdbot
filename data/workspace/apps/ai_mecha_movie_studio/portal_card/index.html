実行方法

投入せず不足モデルだけ調べる（/object_info と突合）:

python scripts/run_comfy_workflow.py workflows/scail2/scail2_wan_api.json --preset scail2 --check-only

実生成して出力を回収する:

python scripts/run_comfy_workflow.py workflows/wan22/wan22_ti2v_5b_t2v_api.json \
    --preset wan22_t2v --wait --dest workspace/sample_mecha_movie/output/wan22

トークンは --set KEY=VALUE で上書き。値はJSONとして解釈するため --set STEPS=20 は整数、--set CFG=7.5 は浮動小数になります。 GUI（Tkinter）は START_HERE.py から起動します。

GPU 調停

長時間の生成前に、RL学習・CAE とのVRAM競合をリースで調停します（本アプリのCLIは自動取得しません）。

python scripts/gpu_arbiter.py status
python scripts/gpu_arbiter.py reap
python scripts/gpu_arbiter.py acquire --owner comfyui --priority 10 --ttl 3600
python scripts/gpu_arbiter.py release --owner comfyui

scripts/ はリポジトリ直下のものです。VRAM不足時は 解像度 → フレーム数 → steps の順に下げます。
