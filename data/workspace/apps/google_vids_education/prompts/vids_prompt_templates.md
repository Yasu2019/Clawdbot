# Google Vids用プロンプトテンプレート

## 1. 全体指示

あなたは製造業の品質教育動画を作成する編集者です。以下の台本をもとに、現場作業者が理解しやすい日本語教育動画を作成してください。

条件:
- 対象: 製造現場・検査員
- トーン: 落ち着いた、実務的、わかりやすい
- 専門用語は短く説明する
- 顧客名・品番・図面番号は表示しない
- BGMは控えめ
- テロップは短く大きく
- 1シーン1メッセージ

## 2. シーン生成プロンプト

### Scene 1: 導入
```
日本の製造現場をイメージした清潔な工場内。品質保証担当のAIアバターが正面を向いて説明する。画面には「今日のテーマ：{title}」と表示。落ち着いた教育動画風。
```

### Scene 2: NG例
```
金属プレス部品の端部を拡大したイメージ。鋭いバリが発生している状態をわかりやすく示す。実在の品番や顧客名は表示しない。赤い注意マークと「NG例：端部にバリ」と表示。
```

### Scene 3: 原因
```
金型、材料、加工条件、検査方法の4つの要因をシンプルな図で示す。過度にリアルな企業情報は出さず、教育用の模式図にする。
```

### Scene 4: 対策
```
作業者がルーペで端部を確認している教育用イラスト。チェックポイントを3つの短いテロップで表示する。
```

### Scene 5: まとめ
```
品質保証担当のAIアバターがまとめを説明。背景は清潔な工場。画面には「見つけたら止める・確認する・記録する」と表示。
```

## 3. ナレーション制御例

```
[落ち着いた声] 今日のテーマは、バリ不良の見つけ方です。
[少し間を置く] バリは小さく見えても、組付け不良やケガにつながる重要な不具合です。
[強調] 見つけたら、自己判断で流さず、必ず上長へ連絡してください。
```

## 4. BGM指示

```
製造業の教育動画に合う、控えめで清潔感のあるBGM。テンポは遅め。緊張感を煽りすぎない。ナレーションを邪魔しない。
```
