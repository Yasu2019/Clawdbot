# 07 API Cost Policy: API消費最小化方針

## 原則

1. 台本生成はローカルLLM優先
2. 根拠抽出はQdrant/Paperless優先
3. 外部AIは最終的な表現改善・動画生成だけに使う
4. 1テーマにつき、Vids投入前のプロンプトを人間が確認する

## 推奨モデル振り分け

| タスク | 推奨 |
|---|---|
| 文書検索 | Qdrant |
| 下書き生成 | ローカルLLM |
| 機密マスク | ルールベース + ローカルLLM |
| 台本校正 | Gemini/GPT/Claudeなど必要時のみ |
| 映像生成 | Google Vids |
| 音楽生成 | Vids/Lyria、必要時のみ |

## 節約テクニック

- まず60秒版で試作する
- 画像生成や動画生成は承認後に行う
- BGMは共通テンプレを使い回す
- アバターは固定キャラクター化する
- NG/OKの模式図は再利用する
