# Image2 × OpenClaw 完全自動QA資料生成プロトコル

目的: OpenClaw上で、IATF/QA文書・不良情報・工程情報をRAGで抽出し、gpt-image-2で教育資料/監査資料/顧客説明用ビジュアルを半自動生成する。

対象成果物:
- IATF内部監査の教育ポスター
- 不良事例の図解カード
- 是正処置報告の概要画像
- 工程フロー/リスク比較スライド用画像
- 顧客説明用の品質訴求ビジュアル

重要方針:
- 寸法保証や合否判定には使わない
- 顧客提出前は必ず人間レビュー
- 生成画像には出典・作成条件・レビュー者を記録
- OpenAIモデル名は gpt-image-2 を標準、未対応環境では adapter で差し替え
