# スパゲッティ図分析 実装メモ

## なぜ追加が必要か

v3までは、MOST・サーブリッグ法・Web Learning・OpenCodeGO連携の枠組みはありましたが、
ユーザー申告により、スパゲッティ図分析コードが未対応でした。

v4では、以下を追加します。

- ゾーン遷移集計
- A-B-A往復検出
- 改善前後比較

## MOST / サーブリッグ法との接続

スパゲッティ図は「歩く」「取りに行く」「戻る」「滞在する」を見るマクロ動線です。
MOSTやサーブリッグ法は、机上の手作業や要素動作のミクロ分析です。

連携例：

1. UWBで、ラベル置場への往復が多いことを検出
2. カメラで、ラベル貼り時の両手待ちを検出
3. サーブリッグ法で、探す・選ぶ・つかむ・運ぶ・置くを分類
4. MOSTで標準時間化
5. 標準作業組合せ票に反映
6. 改善後のUWBで動線短縮を確認

## 推奨初期運用

- 最初は台車・箱・治具タグで検証
- 次に匿名作業者タグ
- 解析はCSVサンドボックス
- 個人名・人事評価への接続は禁止
