# Character Sample Upload Folder

Place texture-included character assets here.

Preferred formats:

- GLB
- FBX
- VRM

Preferred asset conditions:

- humanoid rig or armature included
- T-pose or A-pose
- textures embedded or placed beside the model
- moderate polygon count
- face, mouth, or eyelid mesh separation if available

After adding files, run the character inspection step before retargeting Mixamo motion.
