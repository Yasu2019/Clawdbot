# Cinema Quality Checklist

## Body Motion
- [ ] 足が滑っていない
- [ ] 膝が逆方向に折れていない
- [ ] 腰が瞬間移動していない
- [ ] 重心が足裏の支持領域から大きく外れていない
- [ ] ジャンプ着地に重さがある
- [ ] ターン時に肩・腰・足の順序が自然

## Face / Eyes / Hands
- [ ] 視線が対象物に向いている
- [ ] まばたきがある
- [ ] 無表情のまま長時間動いていない
- [ ] 指が硬直していない
- [ ] 手首が破綻していない

## Cloth / Hair / Secondary Motion
- [ ] 髪が体を突き抜けていない
- [ ] 服が爆発していない
- [ ] 揺れが大きすぎない
- [ ] 動きの余韻がある

## Cinematic
- [ ] カメラが動作の意味を見せている
- [ ] 照明が顔と動作を見せている
- [ ] モーションブラーが過剰でない
- [ ] 背景と接地が一致している
