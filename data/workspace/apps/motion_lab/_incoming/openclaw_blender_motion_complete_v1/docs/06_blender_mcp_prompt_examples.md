# 06 Blender MCP 指示例

## シーン作成
可愛い女の子の部屋を作成してください。ベッド、机、本棚、カーテン、暖色ライトを配置してください。既存ファイルは上書きせず、scene_room_v001.blendとして保存してください。

## Mixamoモーション適用
assets/motions/raw にあるMixamoのwalking.fbxを読み込み、main_girlのVRMリグへリターゲットする準備をしてください。まずボーン名対応表を出力し、変更は行わずdry-runで報告してください。

## BVH適用
BVHファイルを読み込み、fpsとスケールを確認してください。root motionを保持する版と、root motionを固定する版を別々に作成してください。

## 品質修正
足滑りがあるフレーム範囲を検出し、接地している足の位置を固定する補正案を出してください。自動修正前に対象フレーム一覧を表示してください。
