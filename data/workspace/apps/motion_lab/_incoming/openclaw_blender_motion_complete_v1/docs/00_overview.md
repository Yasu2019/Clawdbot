# 00 概要：AIディレクター型3D自然動作生成

## 目標
台本・動画内容・場面説明から、Blender上でキャラクターに自然な動作を付ける。特に以下を重視する。

- Mixamoモーションの活用
- BVHライブラリの活用
- VRMキャラクターへの適用
- Rokoko系FBX/BVHの活用
- Blender MCPによる言語操作
- OpenClaw Portalへの統合候補化
- Codexによる既存環境との融合可否判定

## 基本思想
AIに「全部作れ」と命令するのではなく、以下の役割分担にする。

| 役割 | 担当 |
|---|---|
| 台本分解 | LLM / OpenCodeGO |
| 動作タグ化 | LLM |
| モーション候補検索 | スクリプト + 人間確認 |
| リターゲット | Blender Python / アドオン |
| 品質検査 | Blender Python + 目視 |
| 修正案生成 | LLM |
| 最終判断 | 人間 |

## なぜMixamo/BVHを必須にするか
AIだけで骨格アニメーションをゼロから生成すると、手足の接地、重心、タイミングが破綻しやすい。MixamoやBVHは実モーションキャプチャ由来または調整済みの動作が多く、自然さの土台として強い。
