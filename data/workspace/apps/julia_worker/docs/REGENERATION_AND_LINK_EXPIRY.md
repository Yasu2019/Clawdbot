# ZIPリンク期限切れ時の復旧手順

ChatGPTのダウンロードリンクは期限切れになることがあります。
期限切れになった場合は、次のように依頼してください。

```text
前回の Julia Numerical Worker 完全統合ZIPを、同じ内容で再生成してください。
```

または:

```text
有効期限切れのため再生成ください。ファイル名は日付付きでお願いします。
```

## ローカル保存推奨

ダウンロード後は以下へ保存してください。

```text
C:\Users\mhn15\Downloads\clawstack_archives\
```

またはClawstack保管用:

```text
C:\clawstack_archives\
```

展開後、ZIP自体も残してください。
後からCodex/Claudeに再投入できます。
