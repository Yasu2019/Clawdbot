# Fleet Intelligence Knowledge

This folder is the read-only meta layer for K10 plus the sub-PC fleet.

It does not replace existing loops:

- `scripts/k10_fleet_idle_dispatch.py` still owns idle job dispatch.
- `scripts/k10_growth_allocation.py` still owns domain growth allocation.
- `scripts/fleet_revolutionary_evolution_loop.py` still owns existing recovery/rollup.

This layer only proposes compound-growth investments across app development, self-growth, knowledge acquisition, and security posture.

## Current Adoption

`ADOPT_PARTIAL`: observation and planning only.

No automatic destructive action, no service replacement, no credential movement, no company-server direct access from K10, and no unbounded self-improvement loop.

## Files

- `collect_fleet_intelligence_knowledge.py`: downloads direct-free public algorithm/security sources and builds `fleet_intelligence_knowledge.db`.
- `fleet_growth_compound_planner.py`: reads existing fleet status files and generates a safe compound-growth plan.
- `fleet_intelligence_rules.json`: compact extracted algorithm rules.
- `fleet_growth_compound_plan.json`: generated current plan.
- `fleet_intelligence_knowledge_report.md`: generated source report.

## Design

The core loop is:

1. Observe existing fleet status and growth gaps.
2. Score compound-growth levers by impact, parallelism, bottleneck relief, learning value, and safety.
3. Propose only bounded next actions.
4. Store outcomes so future cycles can improve allocation quality.
