# UE5 × Unity 6 デュアルエンジン・ハイブリッド構成仕様書

## 1. 開発ビジョン
本仕様書は、学園恋愛シミュレーションにおいて**「広いユーザー層（低・中スペックPC対応）」**と**「高い市場競争力（映画級グラフィックス）」**を両立するためのアーキテクチャ設計を定義します。

---

## 2. システム構成

```
+-----------------------------------------------------------------------+
|                    UE5 MCP Backend (ハイエンド環境)                    |
|  - Lumen (リアルタイム大域照明)                                        |
|  - Nanite (超高精度3D学園ステージ)                                      |
|  - High-End Cinematic Rendering (告白シーン・PV用動画)                 |
+-----------------------------------+-----------------------------------+
                                    |
            [アセット・テクスチャ抽出 | プリレンダリング動画]
                                    v
+-----------------------------------------------------------------------+
|                    Unity 6 Frontend Client (全ユーザー対応)            |
|  - URP トゥーンシェーダー (VRoidアニメキャラクター)                     |
|  - パラメーター育成・スケジュール計算 (PlayerStats.cs)                 |
|  - ローカルAIリアルタイムツンデレ対話 (Ollama Qwen3:8b)                |
|  - CinematicVideoPlayer (画質設定に応じたカットシーン切替)             |
+-----------------------------------------------------------------------+
```

---

## 3. 実装機能と役割分担

| コンポーネント | エンジン | 役割 | 対象スペック |
| :--- | :--- | :--- | :--- |
| **ゲーム本編・AI対話** | Unity 6 (URP) | 日常のパラメーター育成、校内遭遇、ローカルAIリアルタイム会話 | 全スペック（内蔵GPU〜） |
| **通常3D演出** | Unity 6 (URP) | リアルタイム3Dアングル切り替え（引き・バストアップ） | 全スペック |
| **映画級カットシーン** | UE5 (Lumen) | 告白イベント、クライマックス、公式PV・ストア動画の超高画質動画 | 全スペック（動画再生のため負荷低） |
| **ライティングマップ** | UE5 → Unity | UE5で計算したLumenライティング環境をUnityのテクスチャとして反映 | 全スペック |

---

## 4. ユーザー体験（グラフィック設定）
プレイヤーは環境に合わせてゲーム内のグラフィック設定を切り替えられます：

- **最高画質（UE5シネマ統合モード）**:
  - イベントカットシーンにUE5最高品質レンダリング動画を採用。圧倒的な美しさを提供。
- **標準画質（リアルタイム3Dモード）**:
  - 全ての演出をUnityのリアルタイム3Dモデルで処理。超軽量かつ高速。
