# 3Dときめきメモリアル風 AI学園恋愛シミュレーション 企画仕様書 (GDD)

## 1. 一文企画
「平日はパラメーターを鍛え、週末は3DヒロインとデートやAI会話を楽しみ、卒業式の伝説の木の下での告白成功を目指す学園恋愛シミュレーション」

## 2. コアループ
1. **スケジュール選択（平日）**:
   - 勉強（文系/理系）、運動、容姿磨き、感性、休養から選択。
   - 主人公のパラメータ変化（例: 勉強で学力UP・ストレスUP、運動で運動UP・ストレスUP、休養でストレスダウン）。
2. **遭遇・ランダムイベント（校内）**:
   - 学力や運動が一定値に達すると、対応するヒロイン（例: 生徒会長、運動部マネージャー）と校内で遭遇。
3. **休日（電話・デート申込み・AI対話）**:
   - 週末に電話でデートに誘い、行先（遊園地、映画館、海、図書館）を決定。
   - 3Dマップ/ステージ上でヒロインと会話。選択肢に加え、ローカルAI (Ollama / Qwen3) が好感度に応じたリアルタイムの会話・反応を返答。
4. **卒業式（最終判定）**:
   - 3年目の卒業式の日、最も好感度の高いヒロインからの告白イベント（伝説の木の下）。

## 3. パラメータ設計

### 主人公パラメータ (PlayerStats)
- **学力 (Study)**: 試験順位、生徒会長ヒロインの好感度閾値に影響。
- **運動 (Fitness)**: 体育祭成果、スポーツ少女ヒロインの好感度閾値に影響。
- **容姿 (Style)**: トレンド感、全ヒロインの第一印象・デート成功率に影響。
- **感性 (Arts)**: 文化祭成果、芸術派ヒロインの好感度閾値に影響。
- **ストレス (Stress)**: 高くなりすぎると体調不良イベント発生（全コマンド効果低下）。

### ヒロインパラメータ (HeroineData)
- **好感度 (Affection)**: 0〜100。高くなるとセリフがツンからデレに変化。
- **友好度 (Friendship)**: 0〜100。友達としての信頼度。
- **爆弾/傷心度 (Bomb/Impression)**: 放置したり放置しすぎると爆弾が点灯し、破裂すると全ヒロインの好感度が急落。
- **性格プロンプト (SystemPrompt)**: LLMに渡すペルソナ（ツンデレ、幼馴染、高嶺の花等）。

## 4. 3D演出とAI会話構成
- **3Dカメラ演出**:
  - 通常会話: バストアップショット
  - 重要な決断/告白: クローズアップ + 背景ぼかし (Depth of Field)
  - 校内・デート風景: 3D環境ステージ
- **ローカルAI連携**:
  - `HeroineAIGateway` から `03_LocalLLM` (FastAPI / Ollama) へリクエスト。
  - プロンプト構造:
    ```
    [System] あなたは学園恋愛ゲームのヒロイン「天野 葵」です。ツンデレな性格で主人公への好感度は65/100です。
    [Context] 場所: 映画館 / 主人公の選択: 「この映画、すごく感動したね」
    [Output Requirement] 2文以内でツンデレな反応を返してください。
    ```

## 5. MVP（初期実装）の範囲
- プレイヤーパラメータ管理機能 (`PlayerStats.cs`)
- ヒロインパラメータ管理機能 (`HeroineData.cs`)
- スケジュール管理・実行機能 (`ScheduleManager.cs`)
- 3D会話・演出マネージャー (`Dialogue3DManager.cs`)
- シネマティック演出マネージャー (`CinematicVideoPlayer.cs`)
- ローカルAI会話生成ゲートウェイ (`HeroineAIGateway.cs`)
- C#単体テスト (`DatingSimStatsTests.cs`)

## 6. 画質設定とUE5ハイブリッド演出仕様
- **目的**: 低・中スペックPCユーザーの動作速度（サクサク感）を維持しつつ、ハイエンドユーザーや宣伝PVで最高峰の視覚表現を実現する。
- **標準画質（リアルタイム3Dモード）**: Unity 6のURP Toon Shaderによる軽快なリアルタイム3D描画。内蔵GPUやポータブルPCでも60fps保証。
- **最高画質（UE5シネマ統合モード）**: UE5のLumen/Naniteでレンダリングした映画アニメ品質の動画カットシーン (`CinematicVideoPlayer.cs`) を重要イベント（告白等）で再生。高精細なライティングテクスチャをUnity側へ反映。
