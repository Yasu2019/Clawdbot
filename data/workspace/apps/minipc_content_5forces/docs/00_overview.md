# 00_overview - 全体像

## このZIPで追加するもの

Portal ダッシュボードに、以下のような流れを追加する想定です。

```text
アイデア入力
  ↓
Content 5-Forces Gate
  ↓
採用 / 保留 / 捨てる / 無料記事 / 有料note / Kindle / YouTube / TikTok / ミニゲーム
  ↓
各生成カードへ渡す
```

## なぜ必要か

生成AIは「作る」ことは得意ですが、  
**売れないテーマを大量生産すると、時間・GPU・API・編集工数を浪費します。**

このゲートは、作る前に以下を確認します。

1. 競合が強すぎないか
2. 誰でもAIで作れる薄い内容ではないか
3. 無料情報で十分ではないか
4. 外部サービス依存が高すぎないか
5. 読者が本当に困っているか
6. 鈴木様の現場経験が差別化になるか

## 5フォースのミニパソコン向け変換

| 5フォース | コンテンツ生成向け意味 |
|---|---|
| 競合 | 同じテーマの記事・動画・本が多すぎないか |
| 新規参入 | AIだけで誰でも量産できるか |
| 代替品 | 無料ブログ、YouTube、ChatGPT回答、既存テンプレで足りないか |
| 売り手 | API、画像生成、動画生成、著作権素材、外部サービス依存が強くないか |
| 買い手 | 読者・視聴者・購入者が切実に困っているか |

## 鈴木様向けの強み

一般的なAI副業記事ではなく、以下に寄せるのが強いです。

- 製造業品質保証
- Excel/VBA
- NEXIV
- IATF16949
- APQP/PPAP
- 品質月報
- 不良率分析
- メンテナンス記録と品質データの融合
- OpenClaw/Portal/ローカルLLM
- 3D/CAE/FreeCAD/Blender/UE5
