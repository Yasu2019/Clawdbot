# 05_content_strategy - 売れる記事・本・動画への展開

## 一番強い基本戦略

鈴木様の場合、以下の順番が現実的です。

```text
note無料記事
  ↓
note有料記事
  ↓
Kindlebook
  ↓
YouTube解説
  ↓
TikTokショート
  ↓
ミニゲーム教材
```

## note向き

- 1テーマ1課題
- 実務の困りごとを解決
- VBAコードやテンプレ付き
- Before/After が明確

例:

```text
NEXIV測定データを検査成績書へ自動転記するVBA実装
```

## Kindle向き

- 複数記事を体系化
- 初心者から実務投入までの流れ
- サンプルコード、帳票例、チェックリスト付き

例:

```text
製造業品質保証のためのExcel VBA自動化入門
```

## YouTube向き

- 画面操作
- グラフ生成
- ExcelやPortalの動作デモ
- 失敗例から改善する流れ

例:

```text
検査成績書の転記ミスをVBAでゼロに近づける方法
```

## TikTok向き

- 問題提起
- 1分以内の小技
- note/YouTubeへの導線
- 結論を先に出す

例:

```text
品質保証で毎月ムダになっているExcel作業3選
```

## ミニゲーム向き

- 教育
- 監査訓練
- 異常検出
- 若手教育

例:

```text
IATF内部監査NGポイント発見ゲーム
```
