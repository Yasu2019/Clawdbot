# 06_guardrails - 安全運用ガードレール

## 外部送信禁止にする情報

以下は外部APIや動画生成サービスに送らないでください。

- 会社名が特定できる内部資料
- 顧客名、品番、図面、寸法、公差
- Gmail内容
- 個人情報
- 内部監査の生データ
- 不適合報告書の実名
- 取引先情報
- 製造条件、原価、見積、価格

## 公開コンテンツ化する場合の変換

| 生データ | 公開用 |
|---|---|
| 実品番 | A製品、B部品 |
| 顧客名 | 自動車部品メーカー |
| 寸法値 | ダミー値 |
| 不良内容 | 一般化した不具合 |
| 会社名 | 架空会社 |
| 実データ | サンプルデータ |

## 生成禁止/注意

- 他者の動画スクリプトの丸写し
- 有料教材の要約販売
- 著作権画像・音声・BGMの無断利用
- プラットフォーム規約に反する大量自動生成
- 医療・法律・税務など専門資格が必要な断定
- 会社内部情報の公開

## 事故防止

- 生成前に「公開可/社内限定/外部送信禁止」を分類
- 有料化前に人間レビュー
- 会社情報を含む場合はローカルLLMだけで処理
- 出力ファイルには `PUBLIC_SAMPLE` などの印を付ける
