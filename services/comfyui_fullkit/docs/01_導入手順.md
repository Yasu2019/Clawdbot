# 導入手順
1. ComfyUI PortableのNVIDIA RTX向け標準版を公式ページから取得。
2. 7-Zipで `C:\AI\ComfyUI_windows_portable` に展開。
3. `config/settings.json` を合わせる。
4. `python scripts\doctor.py`。
5. `python scripts\model_manager.py install sdxl_base`。
6. ComfyUIを公式run_nvidia_gpu.batで起動。
7. SDXLテンプレートまたはAPIサンプルで確認。
8. `python scripts\model_manager.py install wan22_5b`。
9. `workflows/video_wan2_2_5B_ti2v.json`を読み込む。
