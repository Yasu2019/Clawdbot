# QA / IATF Use Cases for Kimi

## 1. Internal audit evidence preparation
Input:
- audit checklist
- process documents
- past findings

Output:
- missing evidence list
- likely weak points
- draft interview questions

## 2. CAPA draft support
Input:
- issue statement
- evidence
- recurrence history

Output:
- structured problem summary
- suspected causes
- evidence gaps
- draft action categories

## 3. Supplier/customer specification comparison
Input:
- old spec
- new spec
- internal control plan

Output:
- changed requirements
- affected internal docs
- implementation concerns

## 4. Massive document summarization
Input:
- 20 to 200 PDFs

Output:
- grouped themes
- top risk items
- action list by priority

## 5. Code/documentation assistant for local apps
Input:
- portal app files
- compose files
- SOP docs

Output:
- architecture summary
- duplication points
- refactor candidates
- missing documentation
