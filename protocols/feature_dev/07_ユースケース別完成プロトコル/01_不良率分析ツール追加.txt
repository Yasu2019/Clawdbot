/feature-dev
目的:
- 指定期間の不良率上位製品を抽出し、一覧表示とグラフ出力を行う機能を追加する

背景:
- 現場では製品ごとの不良率比較に手間がかかる
- 日付指定、製品絞り込み、不良数強調などをワンボタンで行いたい
- SQL Server のデータを参照するが、絶対に書き込みはしたくない

対象:
- 既存の Excel VBA または Python 集計ツール
- 読み取り用 SQL 参照処理
- グラフ表示部
- ユーザーフォームまたは入力UI

最重要制約:
- DB は READ ONLY
- SELECT のみ
- 既存の帳票列構成を壊さない
- ユーザーがボタン1つで実行できること
- 不良率と不良数の両方を見える化すること

進め方:
1. Explorer として既存コードの流れ、参照テーブル、既存UI、既存グラフ処理を調査
2. Architect として
   - 最小変更案
   - 既存フォーム活用案
   - 将来拡張も考えた部品化案
   の3案を比較
3. 今回は現場導入優先で、操作が単純で変更量が少ない案を優先
4. 実装後、Reviewer として
   - SQL の安全性
   - 不良率計算式の妥当性
   - 指定期間処理
   - データ0件時の挙動
   - グラフ崩れ
   を確認
5. まとめを残す

必須出力:
- 参照テーブルと実行 SQL 一覧
- 変更ファイル一覧
- 実装内容要約
- テスト項目
- 現場向け操作説明
- ロールバック方法

禁止事項:
- 書き込み SQL
- 既存シート破壊
- 無関係なリファクタ
