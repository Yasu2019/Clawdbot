/feature-dev
目的:
- 新しい業務アプリを Portal カードとして追加または既存カードへ統合する

背景:
- 機能の乱立を避けたい
- 既存カードとの重複を先に確認したい
- Docker / nginx / Portal との整合を取りたい

対象:
- Portal フロントエンド
- 関連するバックエンド API
- docker compose
- メニューやカード一覧

制約:
- まず競合調査を行う
- 全面採用 / 部分採用 / 保留 を判定する
- ポート競合禁止
- 既存運用に影響を出さない

必須出力:
- 競合調査
- 判定結果
- 実装方針
- 起動確認手順
- ロールバック手順
