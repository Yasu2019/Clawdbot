# Claude Code feature-dev 現場投入パック

この ZIP は、Anthropic の Claude Code 公式プラグイン **feature-dev** を、
品質保証・業務改善・社内ツール開発の現場でそのまま使える形に落とし込んだ実務パックです。

## 目的
- 「動くは動くが、レビュー修正ループが止まらない」状態を減らす
- 仕様漏れ・設計漏れ・レビュー漏れを、構造化プロセスで先回りする
- 品質保証部門でも扱いやすい形で、AI開発を標準化する
- 既存の Docker / Portal / ローカルLLM / RAG 環境に安全に組み込む

## このパックに入っているもの
1. 導入方針
2. 実行手順書
3. feature-dev 用プロンプト雛形
4. QA/IATF 観点のレビュー基準
5. SQL 読み取り専用・安全設計ルール
6. Portal / Docker 統合ガイド
7. 代表ユースケース別の完成済み指示書
8. Claude Code に貼るだけの実行プロトコル
9. 受入判定シート
10. 現場運用の禁止事項とエスカレーション条件

## 想定利用者
- 品証
- 製造技術
- 業務改善
- 社内アプリ開発担当
- Codex / Claude Code / Antigravity を併用する人

## 前提
- Claude Code が導入済み
- feature-dev プラグインが利用可能
- リポジトリ配下で作業する
- 実運用前に必ず検証環境で実行する

## 推奨運用方針
- 最初から「コードだけ」を作らせない
- 必ず「目的・制約・出力物」をセットで渡す
- 変更前に Explorer の調査結果を確認する
- Architect の複数案から採用理由を明示する
- Reviewer の指摘は証拠付きのみ採用する
- DB は読み取り専用を原則とする
- 監査対象になる業務は、決定事項を必ず記録する
