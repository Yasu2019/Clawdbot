# Claude Code 向け実行プロトコル（Portal統合判定版）

```text
/feature-dev
目的:
- 新機能を既存 Portal / Docker 環境へ組み込むべきか判定し、実装する

追加指示:
- まず既存カードや既存サービスとの重複を探索すること
- 「全面採用」「部分採用」「保留」の3分類で判定すること
- 既存カードへの吸収が妥当なら、新規乱立を避けること
- docker compose の変更は必要最小限にすること
- ポート競合を確認すること

必須出力:
- 競合候補
- 判定理由
- 採用方針
- 実装または保留提案
- 起動確認手順
```
