# QA業務アプリ向けテンプレ

```text
/feature-dev
目的:
- 品証部門が使う社内ツールに、新機能を安全に追加する

背景:
- 現場では集計、監査、帳票、異常検知を Excel や手作業で運用している
- 改修時に仕様漏れやレビュー漏れが起きやすい
- 実装だけでなく、テストと説明可能性が必要

対象:
- リポジトリ内の既存 QA ツール
- 既存の UI / Python / VBA / SQL 読み取り処理

制約:
- SQL は読み取り専用
- 業務停止につながる変更は禁止
- 出力帳票の列順と意味を勝手に変えない
- エラーメッセージは現場担当者が読める日本語にする
- 変更理由をまとめに残す

出力物:
- Explorer による現状調査
- Architect による複数案比較
- 採用案の理由
- 実装コード
- テスト手順
- 現場向け簡易説明

受入条件:
- 現場が既存手順から大きく外れずに使える
- 出力値の根拠が追える
- 異常時の挙動が説明できる
- リグレッション観点が整理されている

レビュー観点:
- IATF 的に説明可能か
- 品証部門の監査に耐えるか
- 既存帳票との整合が取れているか
```
