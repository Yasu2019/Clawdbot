# SQL 読み取り専用厳守テンプレ

```text
/feature-dev
目的:
- 既存 SQL Server データを参照して分析・表示する機能を追加する

最重要制約:
- DB は絶対に READ ONLY
- INSERT / UPDATE / DELETE / MERGE / DROP / TRUNCATE / ALTER を禁止
- 一時テーブルやストアド実行も、書き込みの可能性があるものは禁止
- 接続は読み取り専用アカウント前提
- クエリは SELECT のみ
- トランザクションでの更新系処理は禁止

追加制約:
- 実行する SQL 文を明示する
- どのテーブルを参照するか示す
- 取得列を最小限にする
- タイムアウトと例外処理を付ける
- 取得結果の整形はアプリ側で行う

出力物:
- 調査結果
- 実行予定 SQL 一覧
- リスク説明
- 実装
- テスト方法

受入条件:
- 書き込み系 SQL が存在しない
- 接続文字列に読み取り専用方針が反映されている
- SQL 失敗時に安全に中断する
```
