# n8n 連携方針

## 方針
本番フローは触らず、必ず「複製フロー」で比較する。

## 手順
1. 現行フローを複製
2. 比較用フロー名を付ける
   例: summary_test_foundry
3. モデル指定だけ差し替える
4. 出力先は別テーブル / 別ファイル / 別メールにする
5. 結果比較後、採用判断を行う

## 比較観点
- 応答時間
- エラー率
- 日本語品質
- 再現性
- ワークフロー全体の安定性

## 禁止
- 本番フローへ直接上書き
- 既存通知先へ即接続
- Foundry 評価を本番業務に混ぜること

## 推奨サンプル用途
- 文書要約バッチ
- 定型メール草案
- テキスト整形
- 日報要約
- ナレッジ整理

## 判断
n8n は「安定性」が最重要。
速度がやや良くても、不安定なら採用しない。
