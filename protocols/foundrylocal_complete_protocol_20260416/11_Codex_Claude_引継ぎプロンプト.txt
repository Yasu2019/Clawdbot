Codex / Claude / 他AIエージェント 引継ぎ用プロンプト
====================================================

目的:
Microsoft Foundry Local を、既存の Ollama / LiteLLM / OpenClaw / n8n 構成へ、
置換ではなく「比較用に併用追加」したい。
ただし、メリットが薄ければ保留でよい。
既存主系（Ollama / Qwen）を壊さず、最小差分で構成してほしい。

前提:
- 既存主系は Ollama
- 主力モデルは Qwen 系
- OpenClaw / LiteLLM / n8n を利用中
- まずは採用判断のための比較運用をしたい
- いきなり全面移行はしない
- ロールバック容易性が最重要
- Windows ベースのローカル環境を想定
- 将来は社内アプリ化・本番配布の可能性あり

依頼事項:
1. Foundry Local を比較系として追加する最小差分の構成案を提示
2. LiteLLM の model alias 設計を提示
3. OpenClaw の接続先設計を提示
4. n8n は本番フローを壊さず比較フローで評価する前提にする
5. ロールバック手順を明示
6. Go / Hold / Stop の判断基準を明示
7. 既存主系は当面 Ollama のままとする
8. 採用前提で押し切らず、保留判断も許容する
9. 変更箇所・戻し方・影響範囲を一覧化する
10. 可能なら、実装ファイル差分の雛形も提示する

出力条件:
- UTF-8 で文字化けしにくいこと
- コピペしやすいこと
- 曖昧表現を減らすこと
- 「比較してから決める」姿勢を維持すること

最終的に欲しいもの:
- 実装プロトコル
- 比較手順
- ロールバック手順
- 判断基準
- 必要な設定雛形
