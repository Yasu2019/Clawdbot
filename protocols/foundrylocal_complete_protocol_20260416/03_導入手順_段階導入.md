# 導入手順（段階導入）

## Phase 0. 事前保全
- LiteLLM 設定ファイルを退避
- OpenClaw 側で利用中モデル名を記録
- n8n フローのバックアップを取得
- 既存 Ollama 疎通確認を実施
- 問題時は「現状復帰」を最優先とする

## Phase 1. Foundry Local 単体確認
1. Foundry Local を単独で起動
2. ローカル API エンドポイントを確認
3. 単純なテストプロンプトで応答確認
4. 長文要約・日本語応答を試す
5. 安定動作するまで LiteLLM に入れない

## Phase 2. LiteLLM に比較系として追加
1. 既存 alias は変更しない
2. local_compare_foundry を追加
3. default model は変更しない
4. 試験時のみ明示指定して呼ぶ

## Phase 3. OpenClaw から限定利用
1. 一部タスクだけ Foundry 側 alias を指定
2. 短文即答、長文要約、コード補助、文書生成で比較
3. 既存経路との品質差・速度差を記録
4. 問題時は即 Ollama に戻す

## Phase 4. n8n 連携評価
1. n8n のテストフローを複製
2. 新フローだけ Foundry 側を呼ぶ
3. 結果を別保存
4. 本番フローは変更しない

## Phase 5. 判断
- 採用: 明確優位あり
- 保留: 差が薄い
- 中止: 複雑化だけ増える

## 推奨評価期間
- 短期 1〜3 日でも可
- 最低 10〜20 ケースは同条件比較する
- 「何となく良い」ではなく、記録ベースで判断する
