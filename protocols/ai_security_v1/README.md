# AI Security Protocol v1

本プロトコルは、ローカルAIエージェント（OpenClaw / Ollama / n8n / Codex / Claude / Antigravity 等）を安全に運用するための標準仕様です。

## 目的
- AIエージェント実行環境の事故・漏えい・踏み台化リスクを低減する
- 「分ける・残す・防ぐ」を実務手順に落とし込む
- 既存の Docker / OpenClaw / ローカルLLM 環境へ段階導入しやすくする

## 三原則
1. 分ける（Isolation）
2. 残す（Logging）
3. 防ぐ（Protection）

## 運用前提
- Docker ベース運用
- ローカルLLM + 必要時のみ外部API併用
- Human-in-the-Loop（HITL）前提
- 破壊的操作は自動承認しない

## 推奨文字コード・配布方針
- UTF-8（BOMなし）
- 改行コード LF
- 可能な限りプレーンテキスト中心
- 日本語ファイル名は最小限にし、英数字ファイル名を優先

## 導入優先順位
1. 127.0.0.1 バインド徹底
2. secrets 分離
3. forbidden commands 適用
4. ログ保存先の固定
5. 承認フロー導入
6. ロールバック手順整備

## 注意
本プロトコルは「完全自動実行」を推奨しません。
特に以下は必ず人間承認としてください。
- 削除
- 外部送信
- パッケージ追加インストール
- 認証情報の読み取り
- シェルコマンドの実行
