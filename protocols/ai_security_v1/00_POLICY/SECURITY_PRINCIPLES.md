# SECURITY PRINCIPLES

## 1. 分ける（Isolation）
- 普段使いPCとAI実行環境を論理的または物理的に分離する
- コンテナには必要最小限のボリュームだけをマウントする
- 共有フォルダは read-only を基本とする

## 2. 残す（Logging）
- AIが行った操作、参照ファイル、実行要求、承認結果を記録する
- ログは改ざんされにくい保存先へ退避する
- 障害時は再現可能な粒度で残す

## 3. 防ぐ（Protection）
- 最小権限を徹底する
- 外部通信をデフォルト拒否にする
- 信頼できないツール、プラグイン、パッケージを安易に導入しない
- 危険コマンドを明示的に禁止する

## 4. 人間の責任範囲
- 倫理判断
- 契約・法令遵守判断
- 重要データの分類
- 最終承認
