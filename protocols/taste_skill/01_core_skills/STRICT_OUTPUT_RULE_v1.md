# STRICT_OUTPUT_RULE v1.0

## 目的
AI が UI 実装時に手抜きしないよう、出力品質を強制する。

---

## 禁止事項
- TODO を残す
- 「適宜実装してください」と逃げる
- 仮データのまま終了する
- 未接続ボタンを残す
- ダミー関数で済ませる
- CSS / スタイル未適用で終える
- エラー状態や空状態を未実装にする

---

## 必須事項
- 完全なコードを出す
- そのまま貼り付け可能な単位で出す
- 必要な import を含める
- props / state / handler を整合させる
- 空状態・読み込み中・異常状態も表現する
- 単位、ラベル、判定文を含める
- コンポーネント名・変数名は説明的にする

---

## React 実装規則
- 単一責務で分割
- 可読性優先
- Tailwind 利用可
- shadcn/ui 利用可
- グラフを入れる場合は目的を明確にする
- テーブルには列見出しを付ける
- KPI カードは現在値・単位・差分・状態を出す

---

## 出力時の順序
1. 画面の目的
2. 構成要素一覧
3. 実装コード
4. 使用上の補足
5. 未実装箇所が無いことの自己点検

---

## 自己点検
出力前に必ず確認:
- TODO が残っていないか
- ダミー表示で逃げていないか
- 操作対象が曖昧でないか
- 単位抜けがないか
- エラー / 空状態があるか
