# 例：品質ダッシュボード生成用プロンプト

以下のルールで React の品質ダッシュボードを実装してください。

参照ルール:
- QA_UI_TASTE_SKILL_v1.md
- QA_UI_AUDIT_SKILL_v1.md
- STRICT_OUTPUT_RULE_v1.md

要件:
- ロット単位で不良率、検査数、不良数、承認状態を表示
- 3秒以内に異常ロットを把握できる
- 期間フィルタ、製品絞り込みあり
- KPIカード、異常一覧、推移グラフ、ロット明細テーブルを含む
- UI は業務向けで派手すぎないこと
- 色だけで状態を表現しないこと
- TODO を残さないこと
- 完全な React コードを出すこと
