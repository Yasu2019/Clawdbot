既存の OpenClaw / n8n / RAG / Local LLM / Portal 構成に導入すべきか評価してください。

【最重要】
- 既存システムの破壊は禁止
- 既存の Docker Compose, volumes, env, ports, routes, Portal cards との衝突を必ず確認
- 採用 / 部分採用 / 保留 を必ず三択で判断
- 不採用でも代替案を提示
- 差分パッチ優先
- トークンや秘密情報をハードコードしない
- “良さそうだから全部入れる”は禁止
- 現場実装可能性、保守性、監査性、ロールバック容易性を重視

【実施タスク】
1. 既存構成の棚卸し
2. 攻撃面の洗い出し
3. どこにスキャンを差し込むべきか設計
4. 最小実装案(MVP)と拡張案(Production候補)を作成
5. 導入に必要なファイル差分、Compose差分、env差分を明示
6. テストケースを Prompt Injection / Jailbreak / Data Exfiltration / Tool Abuse に分類
7. 結果を人がレビューしやすい報告書形式にまとめる

【出力形式】
1. 結論
2. 採用判断（三択）
3. 理由
4. 衝突確認結果
5. 差分設計
6. セキュリティ試験計画
7. ロールバック手順
8. 未確定事項・要一次情報確認点
